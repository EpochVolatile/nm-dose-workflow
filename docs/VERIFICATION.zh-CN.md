# 本机验证记录与边界

验证日期：2026-10-24，Windows + AlmaLinux-9.6 WSL 2，x86_64。软件版本见 README。完整原始数据和日志保留在本机 `~/sim-data/nm-dose-workflow/20261024-final/`，没有上传到 GitHub。

## 实际执行

1. 在独立 venv 安装 OpenGATE 10.1.1、配套核心和数据库，实际导入并运行模拟。
2. 使用 24 个角度、每角度 20,000 个光子生成 ROOT 相空间记录，共 480,000 个成像光子；对能量和方向筛选后形成投影。
3. 执行 SimpleITK CT/标签参考网格转换，保留物理坐标记录。
4. 使用 PyTomography 3.4.0 的 SPECTSystemMatrix、Poisson likelihood 和 OSEM，CPU、8 次迭代、4 子集。
5. 使用已定标重建活度作为 GATE 的 Lu-177 离子源，实际运行 100,000 个母核衰变事件，输出剂量及相对统计不确定度。
6. 在真实 Slicer 5.12.4 进程中导入 OpenDose3DLogic 与 MonoExponential，计算积分并保存包含 CT、活度、剂量和分区的 MRB 场景。
7. 生成并检查本地结果图；核对偏心热点位置、单位和共同显示色标。
8. 再次运行安装入口；从 MRB 重新加载场景，确认保留 Bq/voxel、Gy、两个分区及约 1 MBq 的活度和。

最初的诊断运行发现 VoxelSource 的 position.rotation 没有改变源图方向；已改为附着体积旋转，并通过 180° 命中位置检查后完整重跑。最终结果不采用该诊断运行的投影或剂量。

## 最终算例数值

| 指标 | 结果 |
|---|---:|
| 真值总活度 | 1 MBq |
| 热点真值平均活度 | 1831.50 Bq/voxel |
| 热点重建平均活度 | 1759.65 Bq/voxel |
| 全图相对 L2 重建误差 | 0.25861 |
| 真值活度质心 `[z,y,x]` | `[3.58974, 14.96154, 16.21795]` 体素 |
| 重建活度质心 `[z,y,x]` | `[3.58924, 14.95648, 16.21598]` 体素 |
| 6 h 单指数积分因子 | 31162.2128832 s |
| 水背景平均积分剂量 | 0.00271890 Gy |
| 热点平均积分剂量 | 0.02009646 Gy |

单指数积分因子的解析值为 `6×3600/ln(2)` 秒，与调用 OpenDose3D 后端的结果在数值精度内一致。由于各时间点是同一空间图像的确定性缩放，这只能验证模型接口和时间单位；不能证明真实患者动力学拟合准确。

相对 L2 误差不是 25.9% 的患者剂量误差；它是当前合成活度图相对于本地已知真值的图像误差，受投影统计、角度采样、插值、衰减近似和迭代影响。

## 已确认的验证范围

- GATE 粒子输运、ROOT 数据读取、坐标/轴转置、理想投影及重建链真实执行。
- 单能平行成像模型和完整 Lu-177 衰变剂量模型是两个有意分开的物理阶段。
- 剂量和活度采用显式归一化；没有把原始计数或单次累计沉积直接标成临床剂量。
- OpenDose3D 使用的是安装副本中的实际拟合类，运行于 Slicer，而非替代公式冒用扩展名。
- 三维图和 MRB、CSV、图像及日志都在本地保存。

## 尚不能据此确认

- 真实准直器、探测器、能量响应、散射校正和相机灵敏度的正确性。
- 患者 CT→材料/密度映射、异质组织剂量或真实多时间点配准。
- 临床定量标定、患者动力学或完整不确定度预算。
- OpenDose3D GUI 的完整临床 Initialization 工作流已由该合成场景自动建立；本项目验证的是明确的外部 GATE 10 数据适配与上游拟合后端调用。
- 任意版本组合或 GPU 重建的兼容性；本次使用 README 中列出的 CPU 软件组合。

本记录发布有限的复现数值，不发布原始算例数据，也不设置额外的自动通过门槛。
